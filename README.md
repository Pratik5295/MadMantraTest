# Gameplay Programmer Assignment

All game demo content is inside the `Project` folder. All assets come from the Unity Asset Store, and the character and animations are from Mixamo; both are freely available online.

## How to Play

Open `Project/Scenes/Sandbox/Sandbox.scene` and press Play.

## Controls

**Gameplay**
- **WASD / Arrow keys:** Move
- **Mouse:** Look around
- **E:** Interact
- **Hold Shift:** Sprint

**Puzzle mode**
- **Mouse:** Look around
- **Left mouse click:** Select a puzzle element
- **Esc:** Exit puzzle mode
